# ArtificalAuth 0.1.4-beta

21.10.2026

- Добавлены отдельные нативные Bedrock-формы регистрации, ожидания подтверждения Telegram и ввода пароля.
- Формы отправляются через Geyser прямо на Velocity; сервер авторизации на Paper не нужен.
- В формах регистрации и ожидания доступны «Обновить окно» и «Выйти».
- Закрытие формы не разрешает вход. Повторно открыть её можно командой `/auth` (или настроенным именем команды).
- После подтверждения входа окно закрывается автоматически. Устаревшие ответы и повторные нажатия не действуют на новый сеанс.
- При вводе пароля показано предупреждение: стандартное поле Bedrock может отображать текст пароля без маскирования.
- Java-игроки продолжают пользоваться прежними диалогами. Без Geyser плагин по-прежнему работает в Java-режиме.
- Настройки и данные аккаунтов версии 0.1.3 сохраняются; новые параметры применяются по умолчанию без перезаписи рабочего конфига.

Техническая информация и ограничения проверки — в `FIX-0.1.4.md`.
