# ArtificalAuth 0.1.1-beta

Исправление от 16.10.2026 для Velocity 4.2.0 и Minecraft Java 1.21.11 (протокол 774).
Все компоненты авторизации работают на Velocity; требуется LimboAPI 1.1.27-SNAPSHOT bfef579.

Исправления:
- Добавлена явная регистрация пакетов Show Dialog (0x8a) и Custom Click Action (0x41) в локальном реестре LimboAPI.
- Проверка соединения выполняется раз в 5 секунд и больше не зависит от 180-секундного времени на авторизацию.
- Окна регистрации, ожидания Telegram и ввода пароля передаются клиенту; ответы на кнопки принимает обработчик Limbo.
- Настройка адреса Bot API необязательна: старый конфиг использует https://api.telegram.org по умолчанию.

Сборка: powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
Готовый файл: dist/ArtificalAuth-0.1.1-beta.jar.
После замены JAR требуется полный перезапуск Velocity. Одновременно устанавливать две версии ArtificalAuth нельзя.
Токен, пользовательские сообщения и accounts.json при исправлении не меняются.

Проверки:
- 48 проверок логики авторизации, постоянного хранения и структуры диалогов.
- integration/run.py запускает отдельный Velocity на 127.0.0.1:25597 и локальный имитатор Telegram на 127.0.0.1:18081.
- Имитатор Java-клиента проверяет передачу окон, привязку, переключение Telegram, ввод пароля и начало перехода на main.
- В тестовой конфигурации main намеренно указывает на незанятый порт 25598: проверяется выход из Limbo, а не загрузка игрового мира.
- Реальный Telegram-токен и производственная база в интеграционном тесте не используются.

Исходники RealDA изучены для сравнения устройства окон. Зависимость от Paper не добавлялась.
