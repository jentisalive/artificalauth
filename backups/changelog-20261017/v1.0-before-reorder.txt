1. Добавлена своя авторизация - ArtificalSMP AUTH.
 - При первом входе появляется окно с кодом и инструкцией для привязки Telegram.
 - После привязки бот выдает случайный пароль из 8 букв и символов, и пускает на сервер.
 - К одному Telegram можно привязать только один аккаунт.

2. Добавлено подтверждение входа через Telegram.
 - После входа на сервер, сессия сохраняется на 5 часов. Но и при входе с другого IP-адреса, или после отсутствия 5 часов и больше, бот спрашивает разрешение на вход. Если принять - вход разрешается. Если нет, то соотвестенно - нет. Игрока попросту выкидывает.
 - Если на сервер зашли с другого IP-адреса, то этот же IP-адрес запоминается вместо предыдущего.

3. В боте можно отключить подтверждение входа.
 - Тогда вместо Telegram будет окно с вводом пароля. По умолчанию подтверждение включено.

4. Добавлено управление аккаунтом через бота:
 - Кик с сервера - выкидывает игрока с сервера.
 - Восстановить пароль - выдает новый пароль и выкидывает с сервера. Старый пароль больше не работает.
 - Отвязать аккаунт - сначала выдает предупреждение и просит подтвердить действие.

5. После отвязки ник блокируется для входа.
 - Вернуть доступ к игровому аккаунту можно только через администрацию.
 
6. Исправлено отсутствие окна авторизации.
 - Исправлено зависание в воздухе с последующим таймаутом.
 - Исправлена передача ответов кнопок и ввод пароля.

7. Создан Velocity - теперь подключение к серверу проходит через прокси.
 - На нём работает авторизация, после которой игрок попадает на основной SMP.
 - Подготовлена общая точка входа для Java и Bedrock.

8. На Velocity добавлены плагины:
 - ArtificalSMP AUTH (Своя авторизация с привязкой Telegram.)
 - LimboAPI (Виртуальная комната для входа, без отдельного сервера авторизации.)
 - Geyser-Velocity (Подключение игроков с Bedrock.)
 - ForcePack (Загрузка серверного ресурс-пака.)
 - Maintenance (Режим технических работ.)
 - MiniMOTD (Оформление описания сервера в списке серверов.)
 - SkinsRestorer (Скины игроков.)
 - VersionBlocker (Ограничение входа по версии Minecraft.)

9. Настроен Velocity, относительно настроек по умолчанию:
 - Вместо стандартных lobby, factions и minigames подключен наш main. После входа игрока направляет на него.
 - Убраны стандартные примеры доменов для перехода на разные серверы.
 - Включена современная передача данных игроков на основной сервер (modern).
 - Отключена обязательная проверка Java-лицензии (online-mode: true → false). За вход отвечает ArtificalSMP AUTH.
 - Стандартное описание Velocity заменено на описание беты ArtificalSMP, с версией и Telegram проекта.
 - Для текущей локальной настройки адрес прокси изменен с 0.0.0.0:25565 на localhost:25564. Основной сервер - 127.0.0.1:25565.
