# ArtificalAuth 0.1.2-beta — 17.10.2026

Исправлен формат ответов на диалоги: VarInt длина + анонимный NBT, TAG_End для отсутствующего значения. Прежний разбор ошибочно ожидал отдельный boolean присутствия и не читал длину на Minecraft 1.21.11. Прежний тестовый клиент воспроизводил ошибочный формат; заменён независимым примером реального пакета.

Кнопки «Обновить», «Выйти» и «Войти» используют исправленный обработчик. Режим after_action=none сохраняет диалог при отмене перехода по ссылке; Waiting for server больше не используется. После успешной авторизации явно отправляется Clear Dialog перед переходом на игровой сервер.

Добавлена команда консоли Velocity: authadmin reload.
Имя команды и подкоманды настраивается в commands.admin / commands.reload-subcommand.
Перечитываются сообщения, параметры авторизации, действия бота, маршрутизация, имена команд. Изменённые учётные данные Telegram перезапускают только его обработчик. Ошибочный конфиг отклоняется; предыдущая конфигурация остаётся в памяти. Аккаунты и привязки не пересоздаются. Уже начатые сеансы сохраняют первоначальный срок ожидания.

После обновления JAR необходим один полный перезапуск Velocity.

Проверки: 64 проверки хранилища, авторизации, настоящего формата пакетов и применения/отката конфигурации. Интеграционный тест отдельного Velocity: регистрация, Refresh, Exit (с сообщением отмены), нативная отправка пароля, выход из Limbo, 35 секунд ожидания, изменение сообщений и имён команд через reload, отклонение ошибочных значений. Реальный Telegram-токен не используется. Отмена браузерного предупреждения проверяется настройкой поведения диалога; визуальное поведение настоящего клиента окончательно проверяется в игре.
